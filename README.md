# 满分助手 · 海旗/拓知版

面向海旗、拓知在线学习平台的浏览器用户脚本，当前版本为 **3.4.8**。脚本提供视频自动播放、按课程目录切换小节、第三方题库检索与答案填写、浮动设置面板和诊断日志。

> **使用前请阅读：**本项目仅供学习、研究和技术交流，不保证答案正确、学时有效或成绩结果。自动化操作可能违反平台规则，也可能影响正常学习记录。请遵守所在学校、课程平台及题库服务的规定，并自行承担使用风险。验证码必须由本人完成，脚本不会识别、代填验证码，也不会伪造学时请求。

## 功能特性

- 自动播放当前可见视频，支持播放倍速、自动静音及失败后的切换策略。
- 按已识别的课程目录切换紧邻小节，支持章末进入下一章第一节。
- 提供目录稳定等待、导航落点校验、切换冷却和单标签页切换锁。
- 验证码出现时暂停自动播放和切换，由用户本人处理。
- 支持单选、多选、判断及部分文本题的第三方题库检索与答案填写。
- 自动提交默认关闭；可配置最低填写率，达到后才尝试点击提交按钮。
- 提供可拖动的浮动面板、运行状态、快捷开关、题号导航和设置页。
- 提供跨页面保留的诊断日志及浏览器控制台诊断命令。
- 配置和题库令牌保存在脚本管理器存储中；不可用时回退到站点本地存储。

## 适用站点

脚本当前仅匹配以下域名及其子域名：

- `haiqikeji.com`
- `tuozhikj.com`

项目名中保留了“银川科技学院适配”，但元数据的实际匹配范围不限于单一学校。平台页面结构变化后，部分或全部功能可能失效。

## 安装

### 1. 安装用户脚本管理器

建议在最新版 Chrome、Edge 或 Firefox 中使用支持传统 `GM_*` API 的脚本管理器，例如：

- [Tampermonkey](https://www.tampermonkey.net/)
- [Violentmonkey](https://violentmonkey.github.io/)

不建议将本文件作为普通 `<script>` 直接注入页面：这种用法不会自动获得远程依赖和完整的跨域请求能力。

### 2. 安装本脚本

在 GitHub 仓库中打开 [`tuozhikeji.user.js`](./tuozhikeji.user.js)，点击 **Raw**。脚本管理器通常会弹出安装确认页；核对源码、匹配域名和权限后再安装。

也可以使用脚本管理器的“从 URL 安装”，填入本仓库中该文件的 Raw 地址。

### 3. 允许依赖加载

脚本会从 `registry.npmmirror.com` 加载 Vue、vue-demi 和 Pinia。若脚本管理器提示加载远程资源，请确认来源后允许。依赖加载失败时，面板不会出现，控制台会显示相应错误。

## 使用说明

1. 打开匹配范围内的平台并正常登录。
2. 进入课程章节、视频、作业或考试页面。
3. 通过浮动面板检查设置。修改后保存，并按面板提示刷新页面。
4. 建议只保留一个前台课程标签页；浏览器可能限制后台页面的定时器和播放行为。
5. 遇到验证码或浏览器自动播放拦截时，按页面提示手动处理。
6. 第三方题库返回答案后，先人工核对，再决定是否提交。

> 自动答题和考试自动切题默认开启。若只需要视频功能，请先在设置中关闭相关选项。关闭助手总开关不会主动暂停已经播放的视频；需要立即停止时，可在控制台执行 `__mfStop()`。

## 默认行为

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 自动播放 | 开启 | 只处理可见视频，每个视频仅尝试一次起播 |
| 自动切换 | 开启 | 按已识别目录尝试切换紧邻下一小节 |
| 切换等待 | 随机 10–20 秒 | 播完、无视频或可跳过的播放失败采用相同等待范围 |
| 章末进入下一章 | 开启 | 从本章末节尝试进入下一章第一节 |
| 播放倍速 | 1 倍 | 强制倍速和防回拽功能默认开启，后者主要在倍速大于 1 时生效 |
| 自动静音 | 开启 | 降低浏览器自动播放被拦截的概率，但不保证一定能自动播放 |
| 无视频/播放失败跳过 | 开启 | 仍受自动切换开关和导航保护条件限制 |
| 普通弹窗处理 | 开启 | 仅尝试点击“确定”“知道了”“关闭”等纯关闭按钮 |
| 验证码 | 本人处理 | 不识别、不代填、不自动关闭验证码弹窗 |
| 自动答题 | 开启 | 默认识别到题目后会请求第三方题库 |
| 考试自动切题 | 开启 | 仅控制被识别为考试页面的切题行为 |
| 自动提交 | 关闭 | 开启后也只尝试点击提交，不代表服务端提交成功 |
| 最低匹配率 | 0.8 | 实际含义为“成功填写题数 ÷ 识别出的总题数”，不是答案正确率 |
| 单标签页切换锁 | 开启 | 降低多个课程页同时切换的概率，但不是强互斥保证 |
| 详细日志 | 开启 | 当前标签页最多保留最近 800 条记录 |

## 第三方题库与网络请求

脚本可能连接以下服务：

| 服务 | 域名 | 可能发送的数据 |
| --- | --- | --- |
| 题库海 | `api.tikuhai.com` | 题干、选项、题型及题库海令牌；未填写令牌时也可能发起请求 |
| 言溪题库 | `tk.enncy.cn` | 配置令牌后发送题干和令牌 |
| 木可题库 | `api.muketool.com` | 题干和题型，不要求配置令牌 |
| 一之题库 | `cx.icodef.com` | 配置令牌后发送题干及授权请求头 |

请注意：

- **默认开启自动答题并不意味着所有数据只保存在本地。**题目内容会被发送给上述第三方服务，请在使用前确认你能够接受其隐私政策、服务条款和答案质量。
- 一之题库当前使用明文 HTTP 地址，可能被浏览器拦截，也存在传输窃听或篡改风险。请勿复用其他账号的密码或高价值令牌。
- 题库返回答案不代表正确答案。脚本按返回顺序尝试第一个能够填写的答案，不会验证其正确性。
- 题库响应会用于面板展示。不要将第三方服务返回的 HTML 或链接视为可信内容。

## 权限说明

| 元数据/权限 | 用途 |
| --- | --- |
| `@match` | 限定脚本在海旗、拓知相关域名运行 |
| `@require` | 加载 Vue 3.3.4、vue-demi 0.14.0、Pinia 2.1.6 |
| `@connect` | 允许向第三方题库发起跨域请求 |
| `GM_getValue` / `GM_setValue` | 保存设置、题库令牌和面板位置 |
| `GM_xmlhttpRequest` | 请求第三方题库；不可用时回退为受同源策略限制的 `fetch` |
| `unsafeWindow` | 访问页面媒体元素、导航和本地存储，并提供诊断命令 |
| `GM_info` | 元数据中的声明；当前版本号主要由脚本内部常量显示 |
| `@run-at document-idle` | 在页面空闲阶段启动 |
| `@noframes` | 不直接在 iframe 中重复启动脚本 |

## 隐私与本地数据

- 设置、题库令牌和面板位置优先存储在脚本管理器中；回退模式下存储于站点 `localStorage`。
- 令牌输入框的密码样式只是视觉遮挡，**本地存储并未加密**。不要在共享浏览器配置中保存敏感令牌。
- `sessionStorage` 保存日志、标签页 ID、停止状态和导航信息；`localStorage` 还保存单标签页租约信息。
- 日志可能包含完整页面 URL、课程和章节名称、节点 ID、视频地址、浏览器 User-Agent 及运行状态。
- 当前代码没有主动上传运行日志的逻辑，日志下载在本地完成。但同源页面脚本可能调用暴露的诊断接口，因此不要在不可信页面环境中存放敏感信息。
- 对外提交问题或分享日志前，请删除令牌、Cookie、个人身份信息及敏感 URL 参数。

## 诊断命令

在匹配页面的浏览器控制台中执行：

| 命令 | 作用 |
| --- | --- |
| `__mfLogText()` | 返回日志文本 |
| `__mfLogDownload()` | 下载 TXT 日志 |
| `__mfLogs()` | 查看结构化日志数组 |
| `__mfLogClear()` | 清空运行日志 |
| `__mfStudy()` | 检查验证码、前台状态、多开和播放状态 |
| `__mfCaptcha()` | 查看验证码观察状态 |
| `__mfCatalog()` | 查看识别出的课程目录 |
| `__mfDiag()` | 查看当前节定位、下一节和阻止切换的原因 |
| `__mfStop()` | 停止自动流程并暂停当前视频 |
| `__mfResume()` | 恢复运行 |

## 常见问题

### 面板完全不出现

检查当前 URL 是否匹配、脚本是否启用，以及三个远程依赖是否加载成功。再查看控制台是否出现 Vue/Pinia 加载错误。

### 视频不自动播放

浏览器可能拦截自动播放，视频也可能不可见或位于跨域 iframe 中。按面板或页面提示手动点击一次，不要反复刷新。

### 视频播完后不切换

检查总开关、自动切换、失败跳过、验证码状态和单标签页锁，再执行 `__mfCatalog()` 与 `__mfDiag()`。目录无法稳定识别或当前节不能唯一定位时，保护逻辑会阻止切换。

### 学时不增长

执行 `__mfStudy()`，检查验证码是否真正通过、视频是否正在播放、页面是否位于前台，以及是否同时打开多个课程页。脚本不控制服务端学时判定。

### 没有检索到答案

检查题库服务是否可用、令牌是否有效、题目 DOM 是否被正确识别，以及请求是否超时或被浏览器拦截。无 `GM_xmlhttpRequest` 能力时，回退请求可能受 CORS 或混合内容限制。

### 作业页没有进入答题流程

当前模式识别会优先处理存在视频上下文或课程目录的学习页，部分作业页可能因此被识别为学习模式。请停止自动流程，导出脱敏日志后提交问题。

## 已知限制

- 目录、题目、验证码和按钮识别依赖平台现有 DOM 结构，无法承诺所有页面均可用。
- 导航保护只能降低误切换概率，不能保证绝不跳错章节。
- 跨域 iframe 中的视频无法直接读取。
- 图片题干、复杂富文本、非标准题型和部分纯文本题可能无法解析。
- “匹配率”是填写率，不是答案正确率、置信度或预计得分。
- 自动提交只尝试点击按钮，不验证服务端结果；点击后仍可能继续寻找下一题按钮。
- 强制倍速和防回拽会修改页面媒体行为，可能影响正常拖动进度或平台记录。
- 脚本启动时会解除部分页面复制、剪切、粘贴、选择和拖拽限制，目前没有独立开关。
- 面板页脚仍显示旧版本号 v3.2.2；当前版本以用户脚本元数据和内部常量 **3.4.8** 为准。
